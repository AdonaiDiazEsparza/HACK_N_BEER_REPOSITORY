# HACK_N_BEER_REPOSITORY

Este es el repositorio que contiene todos los documentos de la exposición en HACK&BEER. 

Los documentos se dividen en 2 partes:

- EDR con archivos de DLL y Driver
- Archivos manifiesto y para los EXE de los consumidores y proveedores de ETW

Los Documentos que pertenecen a la explicación para EDR son:
- DRIVER
- edrHackAndBeer
- HackAndBeer
- ExecHackAnd

Para los archivos de ejemplo de ETW de un consumidor y un proveedor estan los ejemplos simples que son
- SimpleProvider
- SimpleConsumer

Para los eventos que se registren en windows se usan los archivos de la carpeta provider:
- myprovider.man
- myprovider.h

Estos estan en conjunto con el proyecto y archivos de ProviderWithETW.
